# Valence

## Platform
Desktop Electron application with a React interface, built and staged on Windows.

## Purpose
A local-first Markdown and plain-text editor. Preserve file content, local settings, document history, session restoration, keyboard commands, and editor modes.

## Current design request
The owner wants the card design developed for Quantos mirrored in Valence, including full customization of colors, text, and spacing. Quantos frontend source is the reference; its remote services and vault APIs are outside this scope.
